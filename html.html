Learn HTML

HTML is the standard language for creating Web pages.

HTML Introduction

HTML stands for HyperText Markup Language. It is used to create the structure of websites.

HTML Basic

Here is a simple HTML document:

<!DOCTYPE html>
<html>
<body>
  <h1>Hello World</h1>
  <p>My first website</p>
</body>
</html>

HTML Elements

HTML elements are written using tags such as <h1>, <p>, <a> and <img>.

HTML Attributes

HTML attributes provide additional information about HTML elements.

<a href="https://example.com"> Visit Website </a>

CSS

CSS is used to style HTML pages.

h1 {   color: blue; }

JavaScript

JavaScript is used to make websites interactive.

button.onclick = function(){   alert("Hello!"); };
