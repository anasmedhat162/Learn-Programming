What is CSS?

CSS is a language used to style HTML pages. You can use it to add colors, sizes, spacing, borders, animations, and layouts.

Simple Example

body {
    background: black;
    color: white;
}

h1 {
    color: blue;
}

Important CSS Properties

color - background - font-size - margin - padding - border - width - height
